# Windows 自动识别测试版

## 第一次使用

1. 打开英雄联盟与助手，在「自动识别」点击「开启自动读取」。程序默认暂停，开启后会记住设置。
2. 海克斯大乱斗选人时，优先通过本机客户端接口读取你当前选中的英雄，连续两次一致才替换助手英雄。其他玩家选择不会进入推荐。
3. 游戏内首次出现强化卡，打开「连接与区域设置 → 预览与校准识别区域」。分别框选候选 1、2、3 的**名称**，尽量避开描述、卡片边框和装饰。
4. 框选「已选文字」或「已选图标」区域。图标行应从第一格左沿到最后一格右沿，包含等宽槽位；选择实际槽位数。不能包含候选卡，否则该已选区域会被停用。默认未启用已选区域，避免猜测 HUD 位置。
5. 保存后，稳定读数会自动更新候选与已选，流派、出装和加点随输入重算。本机对局接口可用时，还会更新英雄、等级和装备。

已选图标行必须在画面上可见；界面隐藏或图标共用时无法确定。可改用展开后的已选强化文字区。改变分辨率、HUD 缩放或界面布局后请重新校准。当前候选默认位置只是起点，并非所有分辨率通用。

## 识别错了如何纠正

- 手动换英雄、改候选、等级或装备后，对应项进入「手动锁定」，自动扫描不会覆盖它；点击解除恢复自动读取。
- 已选强化误读时点击移除。本局后续扫描不会重新加入该强化；在自动识别面板点击「不再添加… · 取消」恢复。你也可以手动再次选择它。
- 选择「我选这个」会记录真实选择并清空当轮候选；系统不会用推荐选项推测你实际选择了什么。
- 点击「开始新一局」清空本局与纠错状态。接口识别到新选人阶段或新比赛时也会重置；接口不可用、阶段不明时建议手动开始新一局。
- 模糊匹配仅作为「最近识别建议」展示，不足阈值不会写入。面板百分比是文字/图像匹配程度，不是经实战统计校准的正确率。

## 连不上或读不到

选人接口自动发现 LeagueClientUx.exe 的本机连接参数，也可用原生选择器指定包含有效 lockfile 的客户端安装目录。空 lockfile 无法连接；助手和客户端权限不同也可能导致发现失败。请检查两者运行权限，程序不会自行提权或修改游戏文件。

接口无法确认模式时，自动识别保持等待。确认自己正在海克斯大乱斗后，勾选「接口无法确认时，我确认本局为海克斯大乱斗」，并指定当前选人/游戏阶段。此项确认在重新启动助手或手动开始新一局时清除。若接口明确返回其他队列，勾选也不会绕过模式限制。选人接口不可用时，可校准英雄名称区域进行 OCR 回退。

窗口列表只包括联盟客户端/游戏标题。发现多个窗口时手动指定；进入游戏后可能需要切换到游戏窗口。最小化、独占全屏、保护捕获或被遮挡可能产生空画面；优先使用无边框窗口或窗口模式，再预览检查。程序不会替你调整游戏画面。

## 技术与验证范围

本机只读 LCU 用于选人与模式；[Riot Live Client Data API](https://developer.riotgames.com/docs/lol#game-client-api) 用于本人的局内英雄、等级、装备和时间。LCU 并非稳定公开协议，国服接口和权限可能不同。强化使用 [Electron 窗口捕获](https://www.electronjs.org/docs/latest/api/desktop-capturer)、[本地 Tesseract.js](https://github.com/naptha/tesseract.js/blob/v6.0.1/docs/local-installation.md) 和固定版本图标模板。

没有云端图片上传、游戏输入模拟、进程内存读取、注入或自动操作。口令不写入日志和本局文件；原始捕获图不保存，用户预览只在本机显示。关闭读取会停止轮询并释放 OCR worker。语言模型与图标随安装包提供。

已用合成窗口覆盖真实 Windows 捕获、离线 OCR、图标匹配、两次稳定更新与手动纠错，并以接口样本验证仅取本人的数据。当前机器的客户端连接参数不可读取、lockfile 为空，尚未完成真实国服选人至对局的全流程验证。不会因此声称实战识别率或各分辨率全面适配。反馈时请说明版本、分辨率、HUD 缩放与失败阶段；截图前遮住昵称和聊天等个人信息。
